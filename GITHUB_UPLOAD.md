# GitHub Upload Guide

## Repository

- Name: `energy-diary`
- Description: `Personal energy-aware daily planner with tasks, mood tracking, calendar and monthly analytics.`
- Topics: `personal-planner`, `energy-tracking`, `mood-tracker`, `todo`, `calendar`, `vanilla-js`
- README: `README.md` (English) and `README.zh.md` (Chinese)

## Steps

1. Create a free GitHub account at [github.com](https://github.com).
2. Click `+` in the top right and choose `New repository`.
3. Name it `energy-diary` and create it as Public or Private.
4. Click `uploading an existing file`.
5. Extract `energy-diary-deploy.zip` and drag the files into the upload page.
6. Do not upload `data.json`; it contains personal data and is gitignored.
7. Commit the files.
8. In repository `Settings -> Pages`, select `main` branch and `/root`, then save.
9. Your demo URL will be `https://<username>.github.io/energy-diary/`.
